= ONTAP 9.17.1 中適用於 AFX 儲存系統的新功能
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
了解ONTAP 9.17.1 中包含的可用於 AFX 儲存系統的新功能。


NOTE: ONTAP 9.17.1 為 AFX 提供了多項新功能。其中一些是 AFX 特有的，而許多其他功能則源自共享的產品庫。除了查看下文所述的 AFX 功能外，您還應該參考 https://docs.netapp.com/us-en/ontap/release-notes/whats-new-9171.html["ONTAP 9.17.1 的新增功能"^]。



[[platforms]]
== 平台

[cols="2,4"]
|===
| 更新 | 描述 


| 平台  a| 
以下NetApp AFX 儲存系統組件以及相關支援技術均可使用。該平台共同提供統一的硬體和軟體解決方案，為高效能 NAS 和 S3 客戶的需求提供簡化的體驗。

* AFX 1K 控制器
* NX224貨架
* Cisco Nexus 9332D-GX2B 和 Nexus 9364D-GX2A 交換機


|===


[[storage-resource-management-enhancements]]
== 儲存資源管理增強

[cols="30%,70%"]
|===
| 更新 | 描述 


 a| 
xref:../manage-data/monitor-debug-storage.html[監控和排除 AFX 儲存系統的故障]
 a| 
在分配給 NAS 協定的 ONTAP 叢集上，新建的 SVM 上建立的 Volume 預設啟用檔案系統分析 （FSA）。FSA 會在 Volume 建立後立即自動啟動，無需額外組態即可提供立即分析功能。

|===
